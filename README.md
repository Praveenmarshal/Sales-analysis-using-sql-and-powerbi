# 🍕 Pizza Sales Analytics Dashboard | SQL + Power BI Project

## 📌 Project Overview

This project focuses on analyzing pizza sales data to uncover business insights and support data-driven decision-making.
Using **SQL for data analysis** and **Power BI for visualization**, an interactive dashboard was developed to monitor sales performance, customer behavior, and product trends.

The goal of this project is to simulate a real-world **Business Intelligence & Data Analyst workflow**.

---

## 🎯 Business Objectives

* Analyze overall sales performance
* Identify top-performing and low-performing pizzas
* Understand customer ordering patterns
* Evaluate sales distribution by category and size
* Generate actionable business insights

---

## 🛠 Tools & Technologies

* **SQL** – Data querying & KPI calculation
* **Power BI** – Dashboard & Data Visualization
* **Data Modeling**
* **Business Intelligence Analysis**

---

## 📊 Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas per Order

---

## 📈 Dashboard Pages

### 🏠 Home Dashboard

* Sales overview and KPI summary
* Daily order trends
* Monthly order analysis
* Sales distribution by category & size

### ⭐ Best Sellers Analysis

* Top pizzas by revenue
* Top pizzas by quantity sold
* Top pizzas by total orders
* Category performance comparison

### 📉 Less Selling Analysis

* Lowest performing pizzas
* Revenue loss identification
* Opportunity analysis for business improvement

---

## 🧮 SQL Analysis

SQL queries were used to:

* Calculate KPIs
* Perform aggregation and grouping
* Generate sales trends
* Identify top & bottom performing products
* Filter analysis by category and size

📄 SQL Queries Documentation included in repository.

---

## 💡 Key Insights

* Classic pizza category contributed the highest sales share.
* Certain pizzas consistently generated high revenue and orders.
* Low-performing products were identified for potential menu optimization.
* Sales trends varied across weekdays and months.
